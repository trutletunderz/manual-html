---

## รูปแบบ

```
{TICKET} · {TIER} · {หัวข้อ}

⭐ ต้องใช้วิจารณญาณ ({N} ข้อ)
  1. {สิ่งที่พบ}
     → {คำถามที่ต้องตอบ}
  2. ...

📊 ข้อมูลประกอบ (ไม่ต้องตัดสิน)
```

---

## ทำไมบรรทัดสุดท้ายอยู่ตรงนั้น

มันคือ**สิ่งสุดท้ายที่เห็นก่อนกดปุ่ม**

ถ้าตอบสามข้อไม่ได้ในหัว แปลว่ายังไม่ควรอนุมัติ —
ไม่ว่าจะเขียวกี่ gate ก็ตาม

## ตัวอย่าง

```
PED-1123 · T2 · ฝากเงินขั้นต่ำ

⭐ ต้องใช้วิจารณญาณ (3 ข้อ)
  1. ข้อความ error ใหม่: "ยอดเงินไม่ถึงขั้นต่ำที่กำหนด"
     → โทนตรงกับที่อื่นมั้ย อ่านแล้วรู้ว่าต้องทำอะไรต่อมั้ย
  2. AC-2 บอก "แจ้งเตือนผู้ใช้" — ทำเป็น toast 3 วินาที
     → พอมั้ย หรือควรเป็น inline error ที่ค้างอยู่
  3. diff แตะ utils/format.ts ซึ่งอยู่นอกขอบเขต ticket
     → ตั้งใจหรือ scope creep

📊 ข้อมูลประกอบ
  gate ผ่าน 18/18 · เทสใหม่ 12 (red-proof ✓)
  diff 4 ไฟล์ +87/−12
  preview: https://pr-123---pedpro.run.app

───────────────────────────
มาจากไหน · อะไรกั้น · ลองรึยัง
```
