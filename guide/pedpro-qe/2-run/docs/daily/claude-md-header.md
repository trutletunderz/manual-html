# บล็อกที่วางหัว CLAUDE.md

วางไว้บนสุด **ก่อนทุกอย่าง** — agent อ่านตรงนี้ก่อนเสมอ

เขียนเป็นข้อเท็จจริง ไม่ใช่คำสั่ง (ตามหลักที่ล็อกไว้)

---

## หมายเหตุ

ข้อ 2 เขียนแบบนี้โดยตั้งใจ — **มันบอก agent ว่าข้อความในไฟล์นี้ไม่ใช่กลไก**
ซึ่งเป็นความจริง และการบอกความจริงตรงนี้ทำให้ทั้งไฟล์น่าเชื่อถือขึ้น
