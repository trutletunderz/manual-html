# สามคำถาม

> ตัวบทหลัก — ที่อื่นทั้งหมดอ้างมาจากไฟล์นี้
> แก้ที่นี่ที่เดียว แล้ว sync ไปที่อื่น

---

## แบบสั้น — สามคำ ใช้ในหัว

```
มาจากไหน      ·   อะไรกั้น      ·   ลองรึยัง
```

---

## แบบใช้งาน — ถามกับงานตรงหน้า

**1 · ถูกต้อง มาจากไหน**
ถ้ามาจากของที่กำลังตรวจ = ถามคำตอบกับคนที่ตอบ

**2 · ลืมแล้ว มีอะไรกั้น**
ขอไม่ให้ทำผิด ≠ ทำให้ทำผิดไม่ได้

**3 · เคยลองรึยัง**
ด่านที่ไม่เคยถูกทดสอบ ไม่ใช่ด่าน เป็นความเชื่อ

---

## แบบประโยคเดียว

> **รู้ให้ได้ว่าอะไรคือถูกต้อง แล้วทำให้ผิดไม่ได้**

ท่อนหน้า = ข้อ 1 · ท่อนหลัง = ข้อ 2
ข้อ 3 ซ่อนใน "ให้ได้" กับ "ไม่ได้" — สองคำที่ต้องพิสูจน์ ไม่ใช่อ้าง

---

## แกน

```
"รู้ได้ยังไงว่ามันถูก"

ถามกับ โค้ด           →  เขียนเทส
ถามกับ เทส            →  มันจับอะไรได้จริงมั้ย
ถามกับ ด่านตรวจ        →  ใส่ของเสียแล้วมันแดงมั้ย
ถามกับ ตัวเอง          →  ไม่บอกตัวเองแล้วยังจับได้มั้ย
ถามกับ บทเรียนที่สะสม   →  มันกลายเป็นกลไกแล้วหรือยัง
ถามกับ เครื่องมือวัด     →  มันยังวัดอะไรได้อยู่มั้ย
```

คำถามเดียว ถามหกรอบ
